# erpnext-devops

A DevOps project built around ERPNext, an open-source ERP system.

The goal is to deploy it and run it properly: automation, backups,
monitoring and security, not just getting it to start.

This repo covers the infrastructure and operations around ERPNext, not
how the ERP itself is configured for a business.
